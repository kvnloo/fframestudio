# Editor-core execution evidence

Generated by the scripts in `test/` and `tools/verify-editor.mjs` against disposable copies.
No production library files are changed. Screenshots are actual Chromium renders.

- `browser/`: desktop + 390px interaction workflow, versions, conflict handling and preferences.
- `acp/`: live Hermes ACP proposal, review, apply, undo, redo and saved readback.
- `perf/`: strict cold-open / 500-clip / scrub / shipped-size observations. See `docs/perf.md`
  for failed thresholds; the presence of a receipt does not mean its budgets passed.
- `perf/run-1/`, `perf/run-2/`, `perf/run-3/`: three consecutive acceptance runs with
  full stdout and exit codes in `perf/runs.json`. All fail the unchanged next-frame gate.
- `profile-before/`, `profile-after/`: Chrome traces (`trace.json.gz`) and optional method
  timings. The after trace retains a worker-dispatch stall, not just the faster observations.
- `profile-summary.json`: generated by `tools/summarize-editor-trace.py` from those traces.
- `browser-after/`: editor interaction workflow after the performance changes.
- `node-tests.txt`, `node-perf.txt`: historical Node test output from before these changes.
